FUNCTION
Tive dificuldade na primeira vez utilizando uma function. A lógica estava correta e a sintaxe também, mas fiquei dando voltas e alterando partes desnecessárias quando, na verdade, precisava apenas chamar a função.
Pensei que precisava de uma variável para chamar a função, mas isso não é necessário.
FOR
Atualmente estou tendo dificuldade com o for. Pensei e montei a lógica corretamente, mas coloquei a impressão no HTML fora do escopo do for.
Eu sei que variáveis declaradas dentro de um escopo não podem ser acessadas fora dele e, mesmo assim, estava tentando encontrar uma forma de levar a variável para fora, quando deveria simplesmente trazer a manipulação do DOM para dentro do escopo.
Minha dificuldade seguinte com o for foi na comparação de valores.
Eu tinha:
const acrescentarHistorico = () => {
    for (let i = 0; i < estoque.length; i++) {

        let nomeLista = estoque[i].nome;
        let quantidadeLista = estoque[i].quantidade;
        let minimoLista = estoque[i].minimo;

        let statusLista = estoque[i].quantidade <= estoque[i].minimo
            ? "Estoque baixo"
            : "Normal";

        document.querySelector("#produto-lista").innerHTML += `<br>${nomeLista}`;
        document.querySelector("#quantidade-lista").innerHTML += `<br>${quantidadeLista}`;
        document.querySelector("#estoque-minimo-lista").innerHTML += `<br>${minimoLista}`;
        document.querySelector("#status-lista").innerHTML += `<br>${statusLista}`;
    }
}

acrescentarHistorico();

Em específico:
let statusLista = estoque[i].quantidade <= estoque[i].minimo
    ? "Estoque baixo"
    : "Normal";

O problema era que, mesmo quando a quantidade era maior que o estoque mínimo, o sistema apresentava "Estoque baixo".
Problema resolvido: os valores capturados dos inputs estavam sendo armazenados como string. Resolvi convertendo os valores de quantidade e estoque mínimo para Number no momento em que eram capturados.
Assim, a comparação passou a ser feita entre números, e não entre strings.
